# Financial Resume

**Financial Resume** is an intelligent personal finance management application designed to simplify expense tracking through the use of **Artificial Intelligence**.  
It automatically analyses invoices, receipts, and payment proofs, extracting key information such as amounts, dates, and entities.  
The application cross-references this data to detect matches between invoices and payments, marks documents as paid, generates detailed transaction reports, and notifies the user about pending charges — all within a simple and intuitive interface.

---

## Features

- **AI Analysis:** Automatically extracts structured data from images of invoices, receipts, and billing notes.
- **Smart Matching:** Links payments to their corresponding invoices based on amount, date, and entity.
- **Transaction Reports:** Generates complete reports summarizing all recorded transactions.
- **Automated Alerts:** Notifies the user about upcoming or overdue payments.
- **Privacy Guaranteed:** All data processing and storage remain under the user's control.

---

## Technologies Used

- **Flutter** — Cross-platform framework
- **Dart** — Main programming language
- **SQLite (sqflite)** — Local database
- **Google ML Kit** — Document detection and text block processing
- **Google Gemini API** — Document interpretation and classification using AI

---

## How It Works

1. The user uploads or scans a document (invoice, receipt, or proof of payment).
2. AI reads and extracts the relevant information using ML Kit for document detection and text blocks.
3. The application stores the data locally and checks if there is a corresponding unpaid invoice.
4. If a match is found, the invoice is automatically marked as paid and the balance is updated.
5. Users can view complete transaction reports generated by the app.
